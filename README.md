# App Multi Actividad Kotlin

Aplicación Android desarrollada en Kotlin que integra múltiples funcionalidades distribuidas en diferentes actividades.

---

## 📱 Funcionalidades

### 🔹 Actividad 1: Saludo
- Captura el nombre del usuario
- Muestra saludo mediante:
  - Ventana emergente (Pop Up)
  - Visualización en pantalla

---

### 🔹 Actividad 2: Login
- Validación de acceso:
  - Usuario: `hz`
  - Contraseña: `123`
- Acceso a funcionalidades principales
- Opción de registro

---

### 🔹 Actividad 3: CRUD (SQLite)
- Insertar registros
- Consultar registros
- Actualizar registros
- Eliminar registros
- Uso de base de datos local SQLite

---

### 🔹 Actividad 4: Registro
- Registro de nuevos usuarios en la base de datos

---

### 🔹 Actividad 5: Cámara 📸
- Captura de foto usando la cámara del dispositivo
- Visualización en ImageView
- Guardado de imagen en la galería

---

### 🔹 Actividad 6: Consumo de API 🌐
- Consumo de API pública: https://randomuser.me/api/
- Obtención de datos de usuario aleatorio
- Visualización de:
  - Foto
  - Nombre
  - Correo
  - Ciudad
- Uso de:
  - Volley (peticiones HTTP)
  - Picasso (carga de imágenes)

---

## ▶️ Cómo usar la app

1. Ingresar nombre y pulsar **Continuar**
2. Iniciar sesión:
   - Usuario: `hz`
   - Contraseña: `123`
3. En la pantalla principal:
   - Usar CRUD
   - Pulsar **Ir a cámara** para tomar foto
   - Pulsar **Ir a API** para consumir datos externos
4. En la API:
   - Pulsar **Cargar usuario**
   - Se mostrará información de un usuario aleatorio
