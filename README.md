# App Multi Activity Kotlin

Aplicación Android desarrollada en Kotlin con 4 Activities:

- Activity 1: saludo al usuario
- Activity 2: login con validación
- Activity 3: CRUD con SQLite
- Activity 4: registro de usuarios

## Funcionalidades
- Captura de nombre y saludo
- Validación de usuario y contraseña
- Registro de usuarios
- Operaciones CRUD con base de datos SQLite

## Tecnologías
- Kotlin
- Android Studio
- XML
- SQLite
