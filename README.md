# App Multi Activity Kotlin

Aplicación Android desarrollada en Kotlin con múltiples funcionalidades distribuidas en varias actividades.

## 📱 Funcionalidades

### 🔹 Actividad 1: Saludo
- Captura el nombre del usuario
- Muestra saludo en:
  - Pop Up (ventana emergente)
  - EditText en pantalla

### 🔹 Actividad 2: Login
- Validación de usuario:
  - Usuario: **hz**
  - Contraseña: **123**
- Acceso al sistema
- Opción para registrarse

### 🔹 Actividad 3: CRUD (SQLite)
- Insertar usuarios
- Leer usuarios
- Modificar usuarios
- Eliminar usuarios
- Conexión a base de datos SQLite

### 🔹 Actividad 4: Registro
- Registro de nuevos usuarios en la base de datos

### 🔹 Actividad 5: Cámara 📸
- Captura de foto usando la cámara del dispositivo
- Visualización en ImageView
- Guardado de imagen en la galería

---

## ▶️ Cómo usar la app

1. Ingresar nombre y pulsar **Continuar**
2. Iniciar sesión:
   - Usuario: `hz`
   - Contraseña: `123`
3. En la pantalla CRUD:
   - Usar operaciones de base de datos
   - O pulsar **Ir a cámara**
4. Tomar foto y guardarla en la galería
